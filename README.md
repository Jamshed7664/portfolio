# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Jamshed7664/portfolio.git
```

Navigate into the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm start
```

Open your browser

```
http://localhost:4200
```
